# Ayla
Cópia independente em `E:\Privacy_Ayla`, preservando frontend, Node/Express, pagamentos e autenticação existentes.

Desenvolvimento: `cd backend` e `npm start`; abra http://localhost:3334. Configuração local usa mock, banco SQLite novo e nenhum serviço externo. Cadastro/login precisam de Supabase próprio; nos testes o Auth é simulado.

Testes: `npm test`, `npm run check`, `npm run audit:security`.
